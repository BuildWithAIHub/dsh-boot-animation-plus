# Changelog

## 0.7.0 — community fork release

Forked from NativeDog1/dsh-boot-animation 0.6.0.

### Added

- **Batch delete in the clip library**: mark several clips, select all / clear,
  confirm, and the plugin removes the files of clips you added yourself.
  Built-in clips are never deletable; the selection is cleaned up afterwards.

### Changed

- The optional welcome layer is **off by default**; the plain full-screen clip is
  the default experience.
- Package renamed to `dsh-boot-animation-plus`; repository moved to
  `BuildWithAIHub/dsh-boot-animation-plus`.
- README/NOTICE rewritten for the fork.

### Removed

- The third-party game intro clip is no longer bundled; only the four DeepSeek
  intro clips are embedded.
